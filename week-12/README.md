# Week 12 — Nov 18

**DATA 110: Data Visualization and Communication**

## Topics

- **Figure design** — A default plot is a draft. Shape, labels, theme, then color.
- **Matplotlib styles** — A style is a starting theme, not a finished figure.
- **Titles and captions** — A figure can have only one title. In a report, it is the first sentence of the caption.
- **Data and context** — The grid should help you read, not compete with the points.
