# Resources

**DATA 110: Data Visualization and Communication**

Shared resources for the course.

## Textbook and readings

- Claus O. Wilke, *[Fundamentals of Data Visualization](https://clauswilke.com/dataviz/)* — required textbook, free online.
- Additional readings and videos will be posted in the weekly folders and on Blackboard.

## Tools

- **Google Colab / Jupyter** — primary environment for notebooks and Python labs
- **Python libraries** — Matplotlib, pandas, NumPy, Seaborn; Plotly and mapping libraries as assigned
- **Tableau** — interactive dashboards
- **GitHub** — version control and selected project submissions
- **Markdown** — documentation in GitHub and notebooks
- **Google Forms / Sheets** — quick data collection and simple tables
- **Blackboard** — syllabus, assignments, grades, and announcements
- **Microsoft Teams** — live class meetings, office hours, and course discussion
