# Project 1

**DATA 110: Data Visualization and Communication**

Project 1 is developed in **Week 8 (October 21, 2026)** and presented in **Week 9 (October 28, 2026)**.

This is a midterm visualization project. Choose a dataset, explore it, and tell a short, evidence-based story with a small set of well-designed charts. The focus is on clear questions, honest encodings, and captions that explain what the reader should notice.

## Expected work

Typical requirements from recent terms (confirm the posted prompt on Blackboard before you start):

1. **Dataset** — Choose a dataset that is rich enough for exploration. You may use a public source (Kaggle, government open data, or a collection provided in class).
2. **Exploratory analysis** — Document structure, missing values, and the relationships you intend to show.
3. **Visualizations** — At least three plots (for example scatter, line, histogram, or bar). Each plot needs a title, labeled axes, a legend when needed, and a caption.
4. **Report** — Introduction, EDA summary, discussion of each visualization, and a conclusion.
5. **Presentation** — A short in-class talk (about 5 minutes in recent terms) with a small slide deck.

## Submission

Submit the report, slides, and code through the location stated on Blackboard. Selected work is often turned in as a GitHub repository link. For the expected GitHub folder layout, see [Github Project Repo.pdf](../Github%20Project%20Repo.pdf).

Students are responsible for confirming that submitted files uploaded successfully. Late work is not accepted unless the instructor approves an exception.

## Rubric (overview)

| Level | What it looks like |
|-------|--------------------|
| **Sophisticated** | On time. Appropriate data. Focused organization. Sourced data. Graphs make an important claim, with labels, titles, and legends. Language is precise. |
| **Acceptable** | Appropriate data and mostly clear graphs. One requirement is missing, or a few parts are thin. |
| **Developing** | Some coherence, but the story or visuals are underdeveloped. Language sometimes gets in the way. |
| **Inadequate** | Late, incomplete, poorly chosen data, or a visualization the audience cannot follow. |
