# Q&A

**DATA 110: Data Visualization and Communication**

Common questions about this course. Official policies are in the [syllabus](../DATA%20110%20Fall%202026%20Syllabus%20CRN21802.pdf).

### Do I need DATA 101 before DATA 110?

No. Some students take DATA 101 first; others take both in the same term. The catalog prerequisite is a C or better in MATH 117/MATH 117A, MATH 217, BSAD 210, or consent of the department.

### Do I need to know Python before this course?

No. You do not need prior Python experience. You do need to practice each week so the labs stay manageable.

### Which Python packages will we use?

Core tools are **Matplotlib**, **pandas**, and **NumPy**. We also use **Seaborn** and, later in the term, **Plotly** and mapping libraries as assigned.

### What is the textbook?

Claus O. Wilke, *[Fundamentals of Data Visualization](https://clauswilke.com/dataviz/)*. The online edition is free. We do not follow the chapters in book order. The weekly folders list the reading that matches that week's plots.

### Why GitHub instead of only Blackboard?

Blackboard is the official place for announcements, grades, and many submissions. GitHub is how data and software work is shared in the field: version history, public links, and reproducible notebooks. Most project work will live in GitHub even when the grade is recorded in Blackboard.

### Why Markdown?

Markdown is the usual way to write readable notes in GitHub and Jupyter/Colab. It is a small skill that shows up in almost every later data course and internship.

### Can I use ChatGPT or Copilot?

Only when the instructor explicitly permits it for that activity, and then you must follow the disclosure and citation directions. Unauthorized or undisclosed AI-generated work may be treated as an academic-integrity violation. You remain responsible for accuracy and originality.

### How should I submit homework?

Follow the instructions on each assignment. Typical workflow is: work in Google Colab or Jupyter, push the notebook to GitHub, and submit the link (or the Blackboard upload) as directed. Confirm that the upload succeeded.

### What counts as excessive absence?

The syllabus defines excessive absence as one more absence than the number of class meetings per week — **2 absences** for this section. If something in your life is getting in the way, contact the instructor early.
