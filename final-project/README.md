# Final Project

**DATA 110: Data Visualization and Communication**

The Final Project is developed in **Week 13 (December 2)** and **Week 14 (December 9)**. Presentations and remaining submissions are due **Week 15 (December 16, 2026)**.

This is the capstone for DATA 110: a visual story supported by exploratory analysis, static charts, and interactive views. Treat it as a portfolio piece.

## Expected work

Typical requirements from recent terms (confirm the posted prompt on Blackboard before you start):

1. **Dataset** — Choose a dataset aligned with your interests, or one from a collection provided in class. Public sources such as Kaggle, the UCI repository, and government open-data portals are acceptable if the data can support a real story.
2. **Exploratory analysis** — Understand structure, distributions, and relationships before you design the final charts.
3. **Visualizations** — A small set of well-designed graphics, including interactive views (Tableau, Plotly, Folium, Altair, or similar). Variety matters more than volume.
4. **Report** — Motivation, EDA, discussion of each visualization, and a conclusion with limitations or next questions. Include reproducible code in the report, an appendix, or a linked notebook.
5. **Presentation** — A short in-class talk. Recent terms used a 5-minute limit and a small slide deck, sometimes with a recorded backup submitted before class.

## Submission

Submit the report, slides, recording (if required), and code through the location stated on Blackboard. Work is often stored on GitHub. For the expected folder layout, see [Github Project Repo.pdf](../Github%20Project%20Repo.pdf).

Students are responsible for confirming that submitted files uploaded successfully. Late work is not accepted unless the instructor approves an exception.

## Rubric (overview)

| Level | What it looks like |
|-------|--------------------|
| **Outstanding** | On time. Rich, appropriate data. Thoughtful EDA. Clear, interactive, well-designed visuals and a coherent narrative. |
| **Proficient** | Focused analysis, useful visuals, and a logical story, with minor gaps in depth or polish. |
| **Developing** | Thin data, missing interactivity, or a report that does not yet tell a clear story. |
| **Insufficient** | Late, incomplete, or too simple to meet the course outcomes. |
