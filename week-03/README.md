# Week 3 — Sep 16

**DATA 110: Data Visualization and Communication**

## Topics

- **Aesthetic mappings** — Position, color, size, and shape as encodings for data (Wilke, Chapter 2).
- **Line plots (`plt.plot`)** — Continuous relationships, functions, and trends over time.
- **Scatter plots (`plt.scatter`)** — Individual observations, variability, and pairwise relationships.
- **Plot customization** — Titles, axis labels, legends, styles, limits, and marker properties.

## Resources / assignment

- Wilke, [Chapter 2: Visualizing data: Mapping data onto aesthetics](https://clauswilke.com/dataviz/aesthetic-mapping.html)
- Matplotlib line and scatter lab (posted here and on Blackboard)

Use line plots for smooth or continuous relationships. Use scatter plots for raw points. Combining both is often the clearest way to show data and a fitted or theoretical curve.
